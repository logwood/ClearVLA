# Legacy research evidence

These notes and tools predate the current independent-mainline contract. They
are retained only to reproduce an old observation or understand why a past
mechanism was tried.

- `conditioned_source_and_dino_study.md`: historical conditioned-source/DINO
  investigation.
- `dino_control_probe_findings.md` and
  `image_stage_probe_findings.md`: compact probe findings.
- `v87_v89_v90_log_comparison.md`: historical cross-version comparison.
- `v98_zero_shuffle_intervention.md`: historical intervention record.
- `tools/`: scripts tied to those archived studies.

Large JSON, PNG and old smoke artifacts were moved out of documentation to
`new_logs/archive/legacy_research_artifacts/` and are ignored by Git. Current
decisions belong in
[`../../CURRENT_MAINLINE_ISSUES.md`](../../CURRENT_MAINLINE_ISSUES.md), not in
new files beside this archive.
