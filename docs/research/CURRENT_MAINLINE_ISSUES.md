# ClearVLA Current Mainline Issues

This is a pure problem ledger for the active Schema37 source. It contains no
repair ancestry and no prospective design. Delete an issue only after its
producer, consumer, backward owner, zero semantics, lifecycle and empirical
boundary are closed.

## IC-06 — dynamic P1 is a large, narrow P2 query refinement

Dynamic P1 receives the summed action query and protected static fact, then
produces `policy_query_residual`. Schema37 keeps the three owners named in
`P2QueryDock`, but its only numerical consumer remains P2:

```text
action_query + factual_base + policy_query_residual -> P2 query
```

It cannot directly write protected fact, consequence, P3 precision,
transition, layer contracts or bottom value.

The last Schema36 observation was dynamic/static RMS
`0.1886 / 0.0180 = 10.5x`, with only about `0.19%` final contract
compression. Schema37 now records matched static/dynamic tensor-gradient RMS,
but a fresh causal intervention is still required to determine whether the
large residual is useful query adaptation or an inefficient narrow carrier.
Do not reduce it by an arbitrary gain or clamp.

## IC-07 — grounding reconstruction owns a private spatial nuisance

`decode_public_position` contributes to DINO reconstruction but is not
exported in `ObjectFactSet`. Grounder loss can therefore improve through
capacity unavailable to S, Teacher, W or P2.

Schema37 records with-position, position-zero and exported-K reconstruction
semantics, but does not change this head. Until a causal study shows the
private term is harmless or makes its useful content available downstream,
grounding reconstruction alone cannot prove online object facts improved.

## IC-11 — G3, learned flow and Teacher association remain unidentified

G keeps differentiated K slots and Teacher preserves camera-aware association,
but their independent action value is not established. The last available run
showed Teacher dustbin about `0.445`, reliability about `0.259`, and best real
match below dustbin. Without a true association label this can represent
calibrated ambiguity or an overly attractive fallback.

Schema37 intentionally leaves Teacher OT, dustbin, flow gain, successor,
transport and covariance algebra unchanged. Do not force nonzero flow, reduce
dustbin by quota, or reinterpret reliability as a loss mask.

## IC-12 — gripper/event behavior remains an experimental risk

The last Schema36 epoch-1 run had good aggregate physical RMSE (`0.09506`) but
over-predicted decoded gripper events (predicted/target ratio about `1.80`) and
had weaker event/motion heads than V120 at the same stage.

Schema37 changes top information ownership and bottom optional routing, so this
observation cannot be assumed fixed or inherited. A fresh run must compare
arm, gripper, decoded event, event head, motion head and hard execution
separately; aggregate RMSE cannot close this issue.

## EXP-01 — Schema37 empirical release gates are not yet observed

Source and CPU contract tests establish algebraic closure, not task quality.
The following remain unknown until fresh experiments:

- production BF16 batch-eight peak memory and median throughput;
- epoch-1 action/first/tail/horizon/arm/gripper/event/motion behavior;
- whether W semantic/appearance/geometry and six P3 lanes receive useful,
  distinct action gradients rather than merely reachable gradients;
- whether a W-effect intervention changes consequence and action without
  improving error when W is removed;
- eight-epoch mean, best point and epoch-6–8 rebound relative to V120.

## Explicitly not active diagnoses

- S no longer discards goal/history/type identity before static P1.
- The public S exit has a shared sample-level RMS contract.
- Typed nonlinear mean correction is no longer discarded.
- W no longer applies a far-owned common-mode gauge.
- W has no dead visibility/persistence status owner.
- P2 retains geometry camera identity through KxC selection and retains
  semantic/geometry typed sidecars.
- Bottom no longer makes complementary P3 lanes compete in one simplex.
- Tensor-level diagnostics now separate S, P1, W, P2 and all six P3 lanes.

Do not reintroduce an item above without new source or experimental evidence.

## Closure rule

An issue is deleted only when all are source-backed:

1. producer and retained axes;
2. every transform, residual/addition point and alternate path;
3. every online and training consumer;
4. loss and ordinary backward owner;
5. zero semantics, dtype and scale/Jacobian boundary;
6. deployment frequency and checkpoint identity;
7. a log or causal observation that tests the claimed behavior.
